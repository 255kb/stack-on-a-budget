## Echolon

[Pricing page](https://echolon.app/pricing)

- *Free tier*: 100% free for personal use, optional commercial version; 100% open source
- *Pros*: A free open source Postman alternative to build and test your APIs.
- *Limitations*: Commercial usage is paid
- *Credit card required*: No

## Scalekit

[Pricing page](https://www.scalekit.com/pricing)

- *Free tier*: 10,000 tool calls and 10,000 trigger events per month, 500 requests per minute, unlimited connected accounts, all 1,100+ connectors and 55,000+ tools
- *Pros*: MCP gateway for AI agents: one endpoint gives an agent tools across Gmail, Slack, Salesforce, GitHub and other apps, each call runs with the end user's own connected account, virtual MCP servers limit which tools each agent can see, and every tool call is logged
- *Limitations*: community and email support only; custom connectors, the API proxy and 90-day tool-call logs are on paid plans
- *Exceeding the free tier*: upgrade to the Growth plan ($99/month) for more tool calls and trigger events
- *Credit card required*: No

## Zuplo

[Pricing page](https://zuplo.com/pricing)

- *Free tier*: 100K requests/month, 1GB egress/month, unlimited environment, developer portal
- *Pros*: Fast way to build an API and manage it through github, developer portal autogenerates documentation for the API, API performance is fast
- *Limitations*: Free tier adds small Zuplo logo to developer portals
- *Exceeding the free tier*: service continues to work and a sale representative contacts the user
- *Credit card required*: No
